Slide 02 · Abstract

What We Built

📋 Executive Abstract

We developed an industry-grade, closed-loop autonomous driving software stack in MATLAB & Simulink, purpose-built for the unstructured Indian road ecosystem.

The system integrates multi-sensor fusion (Camera + LiDAR + Radar), class-specific intent prediction for Indian road agents, a Behavioral Stateflow FSM, and a real-time adaptive polynomial trajectory optimizer — all running in a sub-50 ms closed loop.

A 3D web-based simulator with live ADAS computer-vision HUD provides a fully interactive demonstration — accessible in any browser with zero install.

🎯 Key Innovations

INCHING Mode — Solving Freezing Robot

Creep at 1.8 m/s through dense crowds; induces pedestrians to yield naturally, breaking deadlock.

Asymmetric Risk Potential Fields

Class-aware elliptical safety envelopes: cattle get 2.8 m lateral buffer, 2-wheelers get 1.6 m — reflecting real unpredictability.

Sub-20 ms Replanning

Quintic polynomial spatiotemporal sampling: 12.4 ms avg vs 50 ms target — 4× hardware margin.

Lane-Free Traversability Grid

2.5D non-lane occupancy costmap: works without any painted markings or structured geometry.
